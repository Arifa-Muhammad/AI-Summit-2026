# AI Summit 2026 — Event Website

A modern, responsive college event website built using HTML, CSS, and Bootstrap 5. This project was created as part of a Web Engineering lab task to practice responsive layouts and Bootstrap components.

## Features

- Responsive navigation bar with section links
- Hero section with event details and call-to-action buttons
- About section highlighting event features
- Event schedule displayed in a responsive table
- Speaker cards with images and topic descriptions
- Registration form with browser-side validation and demo success message
- Footer with quick links and contact information
- Responsive layout for desktop and mobile screens
- Smooth scrolling and hover effects

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- JavaScript

## Project Structure

```text
AI-Summit-2026/

```

## How to Run Locally

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.

## Important Note

This is a front-end demonstration project. The event details and sample speaker information are illustrative, and the registration form does not save submissions to a server or database.

## Learning Objectives

- Practice semantic HTML structure
- Use Bootstrap's grid system and responsive utilities
- Style a professional event landing page with CSS
- Add basic client-side form interaction with JavaScript
